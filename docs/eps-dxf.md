# EPS / DXF 的打开、编辑与保存

此功能包含在预览 `0.7.0-kaleiform.6` 的源码及 macOS Apple Silicon 下载包中。

## 使用

1. “文件 → 打开”选择 `.eps` 或 ASCII `.dxf`；DXF 可选择布局、单位和导入比例。
2. 对成功导入的矢量对象进行选择、移动、缩放、节点编辑、填色和描边等操作。
3. “文件 → 保存”写回同格式；“另存为”可选择 EPS 或 DXF，也可保留原件另存新文件。
4. 首次另存时显示对应的中文格式选项。保存选项会记住，后续保存不需要重新设置。

保存和另存为写入一个完整绘图文件，不只保存当前选中对象。只导出选中内容或按画板
分别生成多个文件，请使用“导出”。“存储副本”不会改变当前文档的路径或未保存状态。

## EPS

- 成功解析的路径可以编辑。虹构保存的 EPS 附带原生编辑数据，再次打开可恢复图层、
  画板、文字、效果、符号和图案；EPS 页面供其他软件查看时，透明效果需要拼合，文字通常转为轮廓。
- 其他软件写出的 EPS 取决于可解析的 PostScript 内容，不能保证完全无损。
- 如果只能读取预览，打开后是图片，不能直接编辑原来的矢量节点；导入警告会说明原因。
- 有导入警告时，覆盖原文件前需要确认。建议另存，并保留原始文件。

## DXF

- 支持 ASCII DXF；可编辑导入的二维路径、文字和图层。保存默认“最大可编辑性”，
  文字尽量保持文字、描边保持带线宽的线。选择“保留外观”则可能将文字和描边转为轮廓。
- 可选择 R12 至 2018 的导出版本、单位、比例和颜色等现有选项。
- **不是完整 CAD 编辑器，也不是无损 DXF 往返工具。** 打开时选择一个布局，将绘图
  映射到虹构画板；其他布局、参数化约束、部分三维/专有实体、原始坐标原点和其他
  CAD 数据不会完整保留。渐变、复杂效果、块结构和位图也存在转换限制。
- 每次重新打开 DXF 后，覆盖该来源文件前均需要确认；另存新文件不会覆盖原件。
- 二进制 DXF 和 DWG 不支持，请先在来源软件导出 ASCII DXF。

## 自动化

`file.saveAs` / `document.save` / `file.saveCopy` 都接受 `format: "eps" | "dxf"`。
直接写回导入来源文件时，如果引擎提示内容损失，先备份并确认，再使用
`acknowledgeLoss: true`；桌面界面会显示确认对话框，不会静默覆盖。

```json
{"command":"file.saveAs","params":{"path":"drawing.dxf","options":{"preserve":"editability","unit":"mm","scale":1}}}
{"command":"document.save","params":{}}
{"command":"file.saveCopy","params":{"path":"drawing-copy.eps"}}
```

测试输入为代码生成的原始图形和手写 ASCII DXF / PostScript，不依赖 Adobe 软件或其资源。
