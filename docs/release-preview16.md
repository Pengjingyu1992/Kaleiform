# 虹构预览 16

版本：`0.7.0-kaleiform.16`。本版发布已在本机验收的 PNG 互通与跨窗口画布拖拽修复。

## 更新内容

- 在 macOS 上，选中图案并拖过源窗口的外边界，可转为原生复制拖拽；先取消窗口内的移动预览，源图保持原位，不新增移动撤销步骤。
- 保留属性面板的独立拖拽入口，以及窗口内的正常移动、撤销和面板拖放行为。
- 无效果、无蒙版的普通单张 PNG 可保留完整原始字节，包括透明度、8/16 位数据、嵌入配置与元数据。
- 多对象、效果或蒙版等情况输出透明外观图；接收时嵌入 PNG，摆放尺寸、旋转与翻转独立于像素尺寸，不链接临时交换文件。
- 兼容叠绘的 PNG 交换格式。与最终本地叠绘构建的双向真鼠标拖拽、接收后的 Delete 和撤销，已有用户验收记录。

完整行为与既有验收证据见 [PNG 互通说明](image-interchange.md)及[验收记录](image-interchange-validation.md)。
本次仅发布虹构，不打包或修改叠绘；其他接收软件的行为取决于其自身支持。

## 质量与隐私边界

原 PNG 字节保留不等于 16 位或广色域编辑：现有编辑/渲染管线仍使用 8 位数据。
效果输出受渲染精度和分配上限限制；依赖背景的混合可能在透明背景上呈现不同外观。

**原图交换包含已有元数据，不是脱敏导出。** 拖拽会向接收应用提供选中内容、图层名及摆放参数。
本机私有临时目录使用 `0700` 权限；为接收应用延迟读取至少保留一天，后续拖拽才清理过期目录。
虹构不为此启动网络服务或上传作品，但接收应用可能自行保存或同步内容。

发布审查覆盖指定提交的源码、新增历史、包内容、图片元数据与二进制字符串；安装包不含个人作品、
设置、恢复副本、最近文件、审查日志、截图或系统字体。源码 ZIP 仅来自发布提交。
提供 `BUILD-INFO.json` 与独立 `SHA256SUMS.txt`；检查不是第三方安全认证。

本地完整门禁使用 `RUST_TEST_THREADS=1 cargo xtask ci`，未跳过原有失败断言。
具体测试结果及下载校验记录随 Release 提供；本次没有改动已验收的拖拽逻辑。

## 下载与限制

从[预览 16 Release](https://github.com/Pengjingyu1992/Kaleiform/releases/tag/v0.7.0-kaleiform.16)下载 macOS Apple Silicon DMG、App ZIP 或 CLI ZIP。
本版为 **ad-hoc 签名，没有 Developer ID 签名与 Apple 公证**；见[安装指南](installation.md)。
既有 MCP 仍默认关闭、仅监听本机，且**没有客户端身份认证或细粒度授权**，只应连接可信客户端。
旧版本与 Linux 下载包不替换；Windows、Linux、浏览器及 VoiceOver 的完整实机流程不在本次发布验收范围内。
