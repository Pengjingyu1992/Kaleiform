# 虹构与 VectorCraft 的区别

## 比较口径

虹构是 VectorCraft 的独立衍生项目，不是重写引擎，也不是官方中文版。
这里比较的是 [UPSTREAM.md](../UPSTREAM.md) 中的固定 `0.4.0` 基线。
发布准备时官方 main 已为 `0.5.0`；后续官方可能已有相同或更好的实现，本文不声称虹构独占这些方向。

简体中文、本地化框架、CJK 排版、图像描摹、MCP、SVG/PDF 和大部分绘图工具在该上游基线中已经存在。
“加入了中文”或“增加了图片转矢量”不是对本版本来源的准确描述。

## 本版本的具体改动

| 改动 | 行为与实现位置 | 验证与边界 |
|---|---|---|
| 独立产品呈现 | `brand.rs`、`chrome.rs`、`titlebar.rs`、`assets/app-icon/` 与平台包装：虹构名称、Kaleiform Logo；macOS 图标在 1:1 画布上带透明安全边距和圆角 | 图标生成及 bundle 模板有自动检查；不包含上游 ArtCraft 商标图 |
| 中文文案与旧设置 | `crates/ui-egui/src/i18n/`、`toolbar.rs`、`apps/vectorcraft/src/main.rs`：保持翻译表架构，翻译工具提示，兼容旧语言设置 | 简体中文跟随系统或手动选择；不强制覆盖用户已选的其他语言 |
| 字体字重回退 | `crates/text/src/fontdb.rs`、`shape.rs`：优先沿用既有回退字体族，再选择最接近请求字重的非斜体字面 | 不提供系统没有的字体；不能保证所有生僻字、字体或变体都覆盖 |
| UI 中西文一致性 | `crates/ui-egui/src/ui_fonts.rs`、`theme.rs`：按字体族记录缺字并接入对应回退，改善字重及基线 | 系统字体不同，实际视觉效果可能不同；并非所有排版问题已解决 |
| 标点安全断行 | `crates/text/src/shape.rs`、`layout.rs`：补充部分禁止行首标点；极窄文本框紧急折行遵守禁则及整形簇边界 | `tests_cjk.rs` 有定向回归；不是新增完整竖排或全面中文印刷标准认证 |
| 浮动面板边界 | `crates/ui-egui/src/dock.rs`：按可用区域限宽高、双向滚动，标题区按最终宽度放置菜单与关闭按钮 | 各面板及多组屏幕尺寸有几何回归；系统缩放与字体差异仍需实测 |
| 新建文档短屏布局 | `crates/ui-egui/src/dialogs/new_document.rs`：预设、标签及参数区滚动，创建操作固定保留 | 有 800×500 / 800×600 等回归；极小窗口不承诺完整布局 |
| 密集描摹交互 | `crates/ui-egui/src/menus.rs`、`canvas.rs` 及引擎选择检查：减少大型选择集重复扫描、限制悬浮轮廓计算 | 改善已发现的无响应路径；不承诺任意尺寸的高保真描摹都不会卡顿或耗尽内存 |
| 忽略白色孔洞 | `crates/trace/src/lib.rs`：量化和去噪后将忽略的白色标签先标记透明，再生成叠色蒙版 | `crates/trace/src/tests.rs` 覆盖白色孔洞；受白色判定阈值影响，不等于自动抠图或忽略所有浅色 |
| 异常 PDF 路径导出 | `crates/pdf/src/export.rs`：在传入导出库前拒绝非有限或绝对值超过 10 亿点的路径坐标，避免已复现的整数溢出与清理期间二次异常 | 固定回归检查异常图形被省略、产生警告且普通图形仍正确导出；不是所有恶意文件的安全保证 |
| 项目入口 | 移除原产品的推广与社区快捷入口，保留法律来源和作者署名 | 不移除许可证要求的版权信息；保留文件格式和设置兼容标识 |

上表的 `brand.rs` 等短文件名属于 `crates/ui-egui/src/`，除非另行注明。

## 仍来自上游的能力

引擎和命令系统、文档模型、撤销重做、工具与面板框架、几何与渲染、文字整形、
SVG/PDF/EPS 等格式、基础图像描摹、自动化接口、插件和跨平台入口均继承上游。
上游本身也依赖众多开源库与字体，见 [NOTICE](../NOTICE)。

## 尚未解决与不作承诺的事项

- 尚未整合该固定基线之后的官方 `0.5.0` 改动。
- 首版仅实际打包验证 Apple Silicon macOS；不是全平台已验证的稳定版。
- 没有 Apple Developer ID、公证票据或商店发行。
- 复杂中文排版、罕见字形、竖排、印前色彩、巨大描摹和专有 `.ai` 兼容仍需逐案验证。
- 沿用的旧应用标识和设置路径可能与 VectorCraft 共用，尚未完成独立配置迁移。
- `ROADMAP.md` 是继承的功能盘点和估算，不是独立验收、性能保证或确定交付日期。

欢迎以可公开、已脱敏的最小文件提交问题与改进建议。
