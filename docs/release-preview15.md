# 虹构预览 15

版本：`0.7.0-kaleiform.15`。发布此前本地预览 13、14 的工作区改进与截图问题修复。

## 更新内容

- macOS 工作区整合文档标签、搜索、撤销与视图控制；检查器使用属性、图层、库和历史四个主标签，小窗口按需覆盖画布。
- 修复隐藏顶栏时原生窗口按钮遮挡工具的问题，缩放与面板开关移到右侧；导出和关于继续由菜单访问。
- 新建画布的宽高使用等宽独立输入框，统一单位、方向、画板数、出血与高级设置的对齐和间距，预留滚动条间隙；底部操作保持可见。
- 恢复副本支持勾选恢复、删除与二次确认后的全部删除；保留对已打开文档和其他运行实例的保护，不修改用户原始作品。
- 属性面板快速操作增加“释放复合路径”，复用已有命令与一步撤销。
- 增加本机 MCP 连接管理、真实连接状态、暂停与停止，以及仅在内存保留的有界活动记录。
- 性能诊断快捷键改为 `Cmd+Alt+F12`（Windows/Linux 为 `Ctrl+Alt+F12`），避免与文档设置冲突。

沿用预览 12 的密集图稿拖动缓存；此次没有新增 GPU 画布、分块渲染或节点简化。
完整工作区与验收边界见[工作区说明](macos-workspace.md)。

## 检查与隐私

本地完整检查使用 `RUST_TEST_THREADS=1 cargo xtask ci`，包含格式、静态检查、测试、资产、品牌、分层及 WebAssembly 门禁。
预览 14 候选在 Linux CI 中发现快捷键冲突，因此未公开发布；本版修正绑定并增加真实键盘事件回归，不跳过原失败断言。
此前在并行优化编译负载下，两项异步拖动队列断言也曾失败；独立拖动回归通过，原始失败保留在本地审查记录。
中文界面、窄窗口、多画板创建、复合路径释放及撤销已实机验收；恢复删除保护使用模拟记录和后端回归，不删除用户真实副本。
最终检查记录、源码提交和校验值随 Release 提供；扫描无凭据发现不等于第三方安全认证。

源码归档仅来自指定 Git 提交，不包含本地计划、审查日志、截图、最近文件、偏好、恢复副本或个人作品。
保留许可证与公开贡献者署名。每版提供 `BUILD-INFO.json` 与独立 `SHA256SUMS.txt`。

MCP 默认关闭、仅监听本机；**当前没有客户端认证或细粒度授权**。
开启后应只连接可信客户端，不要转发公网；外部客户端可能将返回内容发送给其模型服务商。
暂停不是回滚，也不取消已受理的后台工作。详见[隐私说明](privacy.md)。

## 安装与范围

从[预览 15 Release](https://github.com/Pengjingyu1992/Kaleiform/releases/tag/v0.7.0-kaleiform.15)下载 macOS Apple Silicon DMG、App ZIP 或 CLI ZIP。
本版为 ad-hoc 签名，**没有 Apple Developer ID 签名与 Apple 公证**；安装提示见[安装指南](installation.md)。
没有打包系统 SF/苹方字体；使用本机已安装字体及既有回退机制。
本次不替换旧版本或 Linux 安装包。Windows、Linux ARM64、FreeBSD、浏览器完整流程和 VoiceOver 实机流程不在本次发布验收范围内。
重要作品请保留原件并经常另存。
