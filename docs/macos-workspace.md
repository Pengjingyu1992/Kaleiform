# macOS 工作区

本地开发版本 `0.7.0-kaleiform.13` 沿用 egui 面板、命令系统与已有 AppKit 材质接入。
这些改动只作用于虹构窗口；系统强调色、减少透明度和减少动态效果是只读适配。

## 布局

- 顶部 52 pt，整合文档标签、新建、检查器开关、主页、搜索、撤销/重做、工作区、导出。
- 默认单列工具栏 56 pt；保留双列、滚动、工具飞出菜单和浮动功能，不截断组名。
- 检查器默认宽 300 pt，可调整；属性、图层、库和历史为四个主标签。
  描摹、对齐、路径查找器默认固定，全部面板菜单可调整固定项，最多七项。
- 宽度小于 960 pt 时，检查器默认收起，通过顶栏或面板命令按需覆盖；打开面板不挤压画布或改变视图坐标。
- 底部合并为 28 pt 状态栏；工具提示在切换后短暂出现，处理耗时移到诊断浮层。
- 上下文操作按选择状态显示，窄窗收为带提示的图标。首页保留最近文件缩略图，预设只在新建窗口。

视口预算不等于无遮挡工作面积：标尺、额外开启的控制栏、浮动条和覆盖面板都须另计。
用户已有工具栏浮动位置、工作区、文档格式、恢复记录和文件兼容标识继续沿用。

## 系统适配

强调色取自 `NSColor.controlAccentColor`。macOS 界面读取本机已安装的 SF 与苹方字体，
不可用时沿用已有字体回退；系统字体不进入仓库或安装包。
正文与控件以 13 pt 为基准，小节使用同字号半粗体，辅助信息 11 pt。
外围材质保持中性；数值、颜色与画布保持稳定的不透明底。
减少透明度时使用实色，减少动态效果时关闭控件动画。

这不是将全部 egui 控件改写为 AppKit；原生控件迁移须另行验收中文输入、焦点与快捷键。

## MCP 本地接口

入口为状态栏 MCP 和“窗口 → MCP 连接”。默认不启动接口；用户可手动启动、暂停请求、恢复和停止。
使用已有 stdio MCP bridge 连接本机控制端口；面板给出可复制的客户端 JSON 配置。
状态来自实际监听与连接计数，不推测客户端名称。活动记录只在内存保留最多 128 项，
含方法名、处理耗时和结果，不记录参数、文档内容、文件路径或令牌。截图请求的“已接收”不代表截图已完成。
暂停拒绝尚未派发的和新控制请求，并清除待执行的合成输入；已受理的后台任务和截图不因此取消，已完成的修改也不会回滚。
停止关闭监听与已登记连接，不等同于取消所有后台工作。

当前控制协议尚未验证客户端身份，也没有命令/文档/文件范围授权。
启动后，本机能够连接该端口的进程可以读取与编辑文档；客户端可能向其模型服务发送工具返回内容。
面板明确显示这个边界，不提供尚未生效的权限、只读或任意历史回滚按钮。
后续认证必须同时覆盖通用命令、批处理和 UI 输入，工具 annotations 不能替代后端授权。

## 性能诊断

“窗口 → 性能诊断”（默认 `Control+Option+Command+P`，避开已有的文档设置快捷键）显示现有画布栅格处理、UI 布局耗时和移动预览状态。
这些是处理阶段的数字，不能称为实际显示帧率、输入到呈现或屏幕发光延迟。
本次布局改造沿用已有密集拖动缓存；没有加入分块渲染、GPU 画布或节点简化。
后续测量分别覆盖首次命中、预览准备、连续交互、松手提交与精确重绘。

分块和 GPU 原型的验收须包括复杂描摹、跨块阴影/模糊/混合/剪切与完整渲染差异。
节点与线段编辑改变了几何形状，不能直接照搬刚体平移的纹理复用。

## 本轮验证

2026-10-19 的最终源码通过 `cargo xtask ci` 全部七项门禁；4,769 项测试通过、5 项忽略，
其中 UI 为 921 项通过、1 项忽略。新增回归覆盖面板可达性、小窗口覆盖、固定项持久化、
MCP 本地暂停/恢复/停止按钮及拒绝请求、停止时断开连接、系统强调色与辅助功能适配。

此前构建已实机查看 1440 × 900 工作区、描摹和 MCP 界面。
最终构建的运行接口确认 800 × 500 下打开覆盖检查器不改变 744 × 420 画布坐标；
但桌面截图接口随后报告没有呈现帧，未把旧截图当作最终构建的新截图。
最终浅色与 200% 缩放的像素检查、VoiceOver 实机流程仍待可见桌面验收。

一次并发运行中密集拖动测试的后台队列断言失败；独立复测及最终完整 CI 均通过，
原始失败保留在本地审查记录，没有通过放宽断言或修改拖动算法消除记录。
本地包为 ad-hoc 签名，严格签名验证通过；没有 Apple 公证，也没有发布 `.13` 到 GitHub。
