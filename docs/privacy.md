# 发布隐私与数据边界

## 首版发布方式

新仓库从经过审查的清洁源码快照开始；开发机上的原仓库和旧历史不改写、不上传。
保留上游原作者版权、许可证、公开贡献者署名与必要来源链接；这些公开署名不是私人凭据。
新提交使用 GitHub noreply 地址，避免发布维护者的私人邮箱。

发布前检查覆盖：

- 将要提交的源文件、文档、配置、注释、示例和新仓库历史中的密钥与个人路径。
- API key、GitHub token、云服务凭据、私钥、个人邮箱、用户目录及内部地址等候选项。
- 图片附加文本 / EXIF 等元数据、示例文档中的链接和路径、WASM 夹具字符串。
- 打包清单、许可证、App 标识、可执行文件架构、签名完整性及二进制编译路径。
- 下载发布后的文件校验值与本地已审查包的一致性。

不上传开发机设置、自动恢复文件、最近文档、日志、私人照片、聊天记录、`.env`、证书私钥、
本地计划目录、构建缓存、原工作目录 `.git` 或系统字体副本。
发布构建映射开发机路径并移除调试符号；使用 Gitleaks 检查凭据候选并人工复核。

macOS 的 App ZIP 和 CLI ZIP 使用同一个打包工具，不写入 Finder 扩展属性或 AppleDouble 元数据。
源码 ZIP 从指定提交通过 `git archive` 生成，不复制工作目录、未跟踪文件或 `.git`。
每版校验清单只列出该版已审查的发布文件，不沿用上一版的校验值。

以上是针对该次发布的检查，不是第三方安全认证，也不是软件不可能存在漏洞的保证。
第三方依赖漏洞和用户后来创建的文档内容不在一次性隐私扫描的保证范围内。

## 使用时的数据

普通本地绘图无需账号、订阅或 API key；虹构没有新增云同步、遥测或作品上传服务。
应用会在本机存储首选项、最近文件、自动恢复和临时导出等数据，可能包含作品内容或路径。
不要把整个设置目录、恢复目录或未经脱敏的日志上传到公开 Issue。

原格式和旧设置兼容机制仍保留，因此虹构与上游可能共享部分本机配置。
安装包不携带维护者的配置，但不意味着运行后不会产生用户自己的本地数据。

macOS 跨应用 PNG 拖拽由鼠标操作显式发起：普通画布移动越过源窗口边界，或使用属性中的拖拽入口，
才向系统拖拽剪贴板提供选中内容。可直接保留的原 PNG 按原始字节传递，**包括已有的嵌入元数据与色彩配置**；
这不是隐私脱敏导出，发送前应自行检查敏感内容。图层名和摆放参数也可能随交换数据传递。
交换会在本机临时目录建立权限为 `0700` 的私有子目录，保存 PNG 与摆放 JSON，接收后在文档中嵌入而非链接临时文件。
为兼容延迟读取，目录会保留至少一天；后续拖拽清理已过期目录，退出应用不保证立即删除。
虹构不为此启动网络服务或上传作品；接收应用如何保存、同步或上传内容由接收应用决定。
更多格式与限制见 [PNG 互通说明](image-interchange.md)。

本地 JSON 控制入口默认关闭，可通过 `--control`、`VECTORCRAFT_CONTROL_PORT` 或“窗口 → MCP 连接”显式开启，
仅监听 `127.0.0.1`；MCP 通过 stdio 或连接本地应用工作。
当前没有客户端身份认证或按文档、命令、文件范围授权；开启后，能连接端口的本机进程可读取和编辑文档。
这些接口有读写文件及导出能力，不应暴露给不可信程序或转发到公网。
面板活动记录仅在内存中保留最多 128 条方法名、耗时和结果，不保存请求参数、文档内容或文件路径。
暂停拒绝新请求与尚未派发的请求，不回滚已完成的编辑，也不取消已受理的后台工作。
外部 AI / MCP 客户端是否把内容发送给模型服务商，由那个客户端和你的配置决定。
系统打印、手动打开链接、在线依赖下载等也可能产生网络访问。

## 报告问题

安全问题按照 [SECURITY.md](../SECURITY.md) 私密报告。
普通 Issue 请尽量使用合成图形或最小示例，移除客户资料、定位信息、图片 EXIF、
绝对文件路径及密钥。若泄露真实密钥，首先在服务提供方撤销或轮换，不仅仅删除公开文本。
