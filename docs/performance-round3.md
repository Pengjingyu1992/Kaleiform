# 性能第三轮

发布版本：`0.7.0-kaleiform.11`，提供 macOS Apple Silicon 预览安装包。以下记录本轮实现与验收边界。

## 解决的问题

选中大量但未达到超大选区阈值的路径时，画布原先在每次刷新逐个从树根查找对象和图层颜色，
右键菜单也逐个查找对象。对象数增加时，查询代价呈平方增长；仅改变选择还会触发整张图稿重新渲染。

## 改动

- 选区对象、所属子图层颜色和需要显示的混合脊线一次遍历收集，按文档、修订和选择复用。
- 右键菜单批量查询对象，保留原选择顺序、适用命令和菜单操作。
- 图稿栅格缓存与选区修订分离。选择或取消选择不再重新栅格化；编辑、撤销、切换文档仍刷新。
- 不透明度蒙版显示、校样、分色与叠印、颜色管理上下文、字体代次及图案边缘色纳入刷新判断。
- 关闭最后一份文档时释放新增的快照缓存。控制通道可查看画布代次和后台是否待完成，便于验收。

第二轮布局、图标、滑块与输入样式保持不变；仍显示原有节点、轮廓、控制柄、参考点和混合脊线。
超大选区沿用原有边界框显示保护。不会为提速简化、删除节点或降低保存和导出精度。

## 验证范围

使用自行生成的 10,000 / 50,000 路径文档进行前后对照，检查重复刷新、右键菜单、
选择变化、编辑/撤销、文档切换、缩放及后台最新请求。回归检查子图层颜色、选择顺序、混合脊线、
图稿纹理不重复上传和关闭文档后的缓存释放。完整质量门禁和本机实际桌面结果另存本地验收记录。

这是大选区界面响应优化，不是局部重绘、GPU 栅格后端或任意文件的帧率保证。
全画布 CPU 栅格刷新、文件解析、复杂几何运算及首次构建缓存仍有成本。
Windows、Linux 和浏览器未进行本轮真实设备性能测试；WASM 通过编译验收。

历史导入模糊测试中出现过随机 SVG 导出 PDF 时的异常退出，尚未稳定复现并定位，
本轮没有将它标为已解决。复杂或损坏输入仍可能暴露其他问题；重要作品请保留原件并使用副本验证。

操作仅涉及虹构代码和应用包。不修改系统设置，不增加网络请求、上传或遥测。
