# 磨砂玻璃界面

从早期预览版 `0.7.0-kaleiform.5` 起提供；可以在应用内关闭。

## 外观和切换

- macOS：虹构 → 外观 → 磨砂玻璃；也可在首选项 → 用户界面切换。
- 四档界面亮度继续可用；关闭磨砂玻璃后恢复原有实色主题。
- 顶栏、工具栏和停靠边栏使用克制的半透明底色。画板、工作区和输入框保持不透明，避免背景干扰绘图及数值阅读。
- 浮出面板和自由浮动面板组使用圆角、细高光边线、阴影及其后方画布的模糊图像。没有可用画布时使用实色底。
- 不引入噪点、动态壁纸、折射动画或额外的品牌资产，不改变图标和工具位置。

## 实现和性能边界

macOS 使用公开的 AppKit [NSVisualEffectView](https://developer.apple.com/documentation/AppKit/NSVisualEffectView)
和 BehindWindow 混合模式。材质放在 Metal 内容视图的后方，同级排列，不接管输入法和窗口事件。
没有使用私有 CGS 模糊接口；原生材质创建失败时自动使用不透明边栏。

浮动面板复用已经完成的画布栅格，不回读 GPU。先缩小到最长边不超过 384 像素，
再交给单独线程模糊；任务队列和待接收结果各只保留一份，面板移动不重新生成模糊图。
切换文档不会显示其他文档的缓存。旋转不匹配时暂停使用旧缓存，等待新图像。
浏览器采用同样的小图缓存，但目前在主线程完成有界模糊。

磨砂只是界面显示层，不进入文档、历史记录或导出图像，不涉及联网服务、API key、遥测或个人图片上传。

## 验证边界

自动化测试覆盖主题切换与设置保存、输入框不透明、小图尺寸上限、模糊边缘和跨文档缓存隔离，
以及原生材质不可用时的实色降级。
`cargo xtask ci` 的格式、Clippy、完整测试、资源归属、品牌、分层和 WASM 七项检查均通过。

macOS Apple Silicon 的 Metal 实机检查覆盖浅色/深色主题、原生材质层级、面板拖动、属性数值输入，
以及 1440×900 和 1050×700 点窗口。使用原创的三色矩形测试图，开关磨砂前后的 PNG 导出字节及撤销记录相同。
该测试图的后台模糊耗时约 2–5 毫秒；这不是大型文档的性能保证。

Windows、Linux 和浏览器的窗口背景仍使用实色，浮动面板保留画布模糊。
这些平台需要后续实机验证；WASM 编译通过不代表完成浏览器交互验收。
系统辅助功能“减少透明度”的实际呈现尚未单独验收，应用内可以完全关闭磨砂。
