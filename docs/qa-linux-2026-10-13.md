# Linux x86_64 预览版验收（2026-10-13）

本次工作补齐 Linux 交付与安装集成，使用现有 Rust 绘图引擎，没有改动应用逻辑或依赖锁文件。
安装方法和构建入口见 [Linux 指南](linux.md)。本地生成了预览包，未上传或发布 GitHub Release。

## 构建

- 构建系统：Ubuntu 22.04.5，glibc 2.35，GCC 11.4，Rust 1.99。
- 命令：`cargo build --release --locked -p vectorcraft -p vectorcraft-cli`，保留仓库 release 的
  thin LTO / 单代码生成单元配置；映射源码与工具目录路径，避免带入云工作目录。
- 两个 ELF 的架构、应用版本及 glibc 符号检查通过；包依赖为 glibc 2.35 以上版本。
- nFPM 2.47.0 的下载文件按官方 release 校验清单验证后使用。
- 格式：deb、rpm、tar.gz、AppImage 及其 zsync 文件；本次生成的 SHA-256 清单验证通过。

图形检查使用 Mesa llvmpipe（LLVM 15.0.7，Vulkan CPU adapter），未依赖物理显卡。
功能脚本使用临时合成作品、禁用首选项持久化，只停止自身启动的应用。

最小运行环境验证发现并修正了原安装清单的缺口：xkbcommon 的 X11 模块缺失会在启动时失败，
Xcursor / XInput 等窗口库仅列为推荐依赖也不足以保证启动；这些依赖现为必需项。
MIME 数据库同样成为必需依赖。新的 Linux CI 在独立 Ubuntu 容器中安装并执行功能检查，
避免构建机预装的开发库掩盖这类问题。
