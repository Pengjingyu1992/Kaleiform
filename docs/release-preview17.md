# 虹构预览 17

本版发布原生 macOS 外观与色彩显示修正，保留预览 16 的 PNG 跨应用互通及既有编辑功能。

## 本次更新

- 窗口、控件、标签和分隔线采用 AppKit 语义颜色；工具选择跟随系统强调色，文档标签保持中性。
- 窄窗口检查器使用内嵌材质，遵循本机减少透明度、减少动态效果偏好。其他平台保留现有主题。
- Metal 的 SDR 显示表面明确标记为 sRGB，在窗口缩放、显示表面重建后继续保持色彩匹配，不修改显示器配置。
- PNG 与 RGB/灰度 JPEG 的显示解码识别嵌入 ICC，以有界批次转换到当前 sRGB 编辑/显示空间，保留 Alpha。
- 原始图片字节、原始色彩配置、PNG 交换及摆放信息保持不变；CMYK 继续使用独立的现有处理路径。

## 验证与来源

`vendor/wgpu-hal` 固定为 crates.io 的 30.0.1 发布包；校验值和唯一 Metal 补丁见
[来源说明](../vendor/wgpu-hal/KALEIFORM.md)，原始许可随 App 提供。不是从其他绘图软件提取的后端或配置。

发布检查包括完整工作区门禁、真实 Metal 显示表面重复配置探针、合成图片测试、包清单与严格签名、
源码归档及发布后下载校验。确切提交、测试结果及签名状态见 Release 的 `BUILD-INFO.json`。
[色彩说明](native-appearance-color.md)中的 2026-10-22 实机测量属于先前本地验收记录，
不应当作本次重新测量、跨显示器性能保证或完整无障碍验收。

## 隐私与限制

- AppKit 偏好和图片色彩配置在本地处理，没有新增遥测、网络服务或作品上传。
- PNG 原图交换保留已有元数据，图层名和摆放信息也可能传递；不是隐私脱敏导出。
- 私有交换目录至少保留一天，后续拖拽清理过期目录，退出不保证立即删除。
- 当前编辑/渲染仍为 sRGB、8 位；原图保留不代表新增广色域、HDR 或 16 位编辑。
- MCP 默认关闭、仅限本机，但仍无客户端认证或细粒度授权，只连接可信程序。
- macOS Apple Silicon 包使用 ad-hoc 签名，没有 Developer ID 与 Apple 公证；不要关闭系统安全检查。
- 本版不覆盖旧版及 Linux 附件，不改变文件格式、兼容标识或功能成熟度评分。
