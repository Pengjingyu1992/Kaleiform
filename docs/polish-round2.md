# 界面质感第二轮

最初实现版本：`0.7.0-kaleiform.10-hotfix.1`。本轮改动已包含在 macOS 预览版 `0.7.0-kaleiform.12`，以下记录实现与验收边界。

## 高频流程

- 首页临时隐藏控制栏、工具栏、侧边绘图面板和绘图状态栏。打开文档后恢复原工作区，已有文档不关闭，面板设置不重置。打开失败等状态信息仍显示在首页。
- 新建文档在窄窗口使用上方预设、下方详情的布局。高级选项在详情区内滚动，创建和关闭按钮不随它滚走。少量最近或已存储预设不再占满默认宽度。
- 图像描摹只滚动参数。预览、结果信息、计算进度、取消、描摹和扩展按钮留在独立操作区。描摹算法、资源限制、过时结果拒绝和撤销事务沿用第一轮。
- 保存保留应用调用的原生 macOS 文件面板及 AI、EPS 等格式选择。应用内保存选项适配窄窗口，在格式菜单或取消按钮上按回车不会顺带保存。

## 键盘与可访问性

共享绘制式按钮、预设卡片、分类标签、方向按钮、复选框和单选按钮补充名称与状态。
键盘焦点有清楚的描边，滚动区只在控件被遮挡时将它带入视野。
模态窗口限制背景交互，新建文档与保存打开时优先选中文件名，Tab 后可按回车操作当前按钮。
用户命名的预设保留原名；最近使用列表中程序生成的 Custom 显示为本地化名称。

## 第二轮收尾

- 描摹操作区使用固定行高，统计、处理中、取消和失败状态共享稳定空间；长信息省略显示，悬浮可读完整内容。失败和取消信息对应当前文档、选择和修订，切换对象或撤销后不会误显示旧任务的状态。
- 新建文档增加文档分类菜单，横向隐藏的分类也能直接选择；短窗口优先保留参数和创建按钮，文件名有可访问标签，自动文档名和预设名随界面语言显示。
- 普通图标命令、开关和展开项使用各自的可访问状态，图像描摹的主按钮和预设菜单有不同名称。Esc 先关闭菜单，关闭对话框后恢复调用处的键盘焦点。
- 首页错误持续显示并可关闭，打开文件失败显示对应文件名并提供重新打开；普通状态六秒后收起。提示不写入偏好设置，历史状态不会在重启后重新弹出。
- EPS 保存选项适配短窗口：参数区滚动，标题和保存、取消按钮固定；AI、EPS 的原生保存、重新打开、编辑和再次保存已用合成图形在 macOS 验证。
- 补充操作区位置稳定、取消与过时任务反馈、首页重试、焦点恢复和可访问树的行为回归。实际桌面验收另行记录，完整 VoiceOver 听读仍需单独检查。

## 验证与范围

第二轮整体轻量化合并完成：属性面板和浮动任务栏使用图标加文字的轻量命令，悬浮、禁用与键盘焦点可辨认；位置与尺寸、文档宽高及出血分别共享输入表面，保留独立编辑、单位运算与步进。普通输入和下拉减少边框强度。描摹模式使用四项分段选择，参数采用可键盘操作的细轨圆形滑块，底部描摹为主动作、扩展为次动作。浮动面板正文使用中性底色。新建预设和最近文件保留完整缩略图与名称，常态减少底板和外框，选中、悬浮和焦点仍明确。

2026-10-16 局部修正：变换组合框补充内边距，旋转输入与位置组合框对齐，九宫格参考点垂直居中；描摹圆形手柄缩小绘制尺寸，保留原来的点击区域、拖动及键盘行为。

回归覆盖四档明暗主题、1x/2x 显示缩放、400/640/800 点宽的新建窗口、短窗口下的固定操作区、
初始焦点、Tab/回车、取消保存、描摹取消以及首页返回文档后的工作区恢复。
仍需结合具体文件和实际显示器使用；自动化检查不等于任意平台、每个工具和所有文档都无缺陷。

本轮不增加重型毛玻璃效果，不改动文件格式、渲染或几何算法，不修改 macOS 系统设置，
不增加网络请求、图片上传或遥测。大文档性能优化属于后续独立工作。
