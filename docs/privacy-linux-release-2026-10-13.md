# Linux 发布隐私审查（2026-10-13）

范围为 Linux x86_64 的 deb、rpm、tar.gz、AppImage、zsync 与独立 SHA-256 清单。
用户已授权向 Pengjingyu1992/Kaleiform 追加 Linux 包；现有 Mac 安装包、源码、构建信息和
Mac 校验清单保持原样。测试使用自行生成的作品，不上传用户文档、截图、偏好、恢复副本、
日志、缓存或包含本地测试报告的合并 ZIP。

## 复核结果

- 应用自有源码未发现遥测、分析 SDK、崩溃报告或作品自动上传服务。
- 可选桌面控制接口只绑定 `127.0.0.1`，由 `--control` 或
  `VECTORCRAFT_CONTROL_PORT` 显式启动。MCP 对外部客户端的数据使用取决于客户端配置。
- 应用在本机保留偏好、最近文件、恢复数据与轮转日志，这些可能含文档路径；发布流程仅取
  打包脚本明确生成的文件，不收集用户目录或这些运行数据。
- 包内容保留原作者、资产来源和第三方许可。CI 重映射源码、Cargo 与 Rust 工具目录，
  发布前扫描便携包全部常规文件中的凭据模式和私人构建路径，拒绝包含配置、日志或本地报告。
- 五份包必须全部通过本次 SHA-256 清单；AppImage 工具按官方 GitHub 资产 SHA-256 固定验证。
  文件扫描降低误带入数据的风险，不代表能识别任意格式的所有秘密。

## 发布保护

Linux 发布仅由 `Linux packages` 的手动触发执行，并限制在 main 分支；输入 tag 必须与
工作区版本相同。构建和运行检查的 job 保持只读，独立发布 job 才获得 `contents: write`。
不删除资产、不移动 tag，不使用 `--clobber`。发布前检查文件名冲突；同名、同哈希的已有
Linux 文件可保留，内容不同则在写入前停止。上传后逐个核对远端 SHA-256，并核对所有原资产
的 ID、文件名、大小和校验值保持一致。Linux 发布说明追加在原 Mac 说明之前，原正文保留。

deb 的独立最小 Ubuntu 安装、桌面绘图/撤销/保存/导出、卸载，以及便携包与 AppImage CLI
运行检查是发布条件。完整功能回归和 JPEG 修复见
[Linux 功能回归](qa-linux-full-2026-10-13.md)。大文档性能仍有超预算项目；Fedora/RPM 安装、
ARM64、真实显卡、数位板和中文输入法尚未完整验收，不将预览包描述为全部功能无 Bug。
