# 稳定性第一轮

最初开发版本：`0.7.0-kaleiform.7`。本轮改动已包含在 macOS 预览版 `0.7.0-kaleiform.12`，以下记录实现与验收边界。

## 图像描摹

桌面应用在后台读取图像快照、计算描摹并生成路径，界面显示解码、颜色、去噪、轮廓/曲线和生成路径等阶段。
面板和状态栏提供取消按钮；焦点不在文字输入框时也可按 Escape 取消。
连续更新参数时，一个后台任务取消后才启动最新请求，不创建无限任务或同时计算多份大图。

取消、计算失败、资源超限、文档/选择改变或切换文档时，结果不会覆盖当前原稿。
成功结果通过原命令事务提交，记录一次操作和一步撤销。原有忽略白色、扩展、释放及描摹视图继续使用。
参数尚未应用或任务未结束时不能扩展。

计算有 120 秒的协作式时间上限、确定性工作量上限，以及按像素数量估算的工作内存上限。
这些限制不是整个进程的硬内存隔离。图片解码库的单次调用不能中途抢占；解码前后均检查取消，
解码始终在后台，现有图片尺寸限制仍适用。系统调度、解码和单次库调用意味着不能保证任意文件在固定毫秒数内完全退出。
输出路径在成功时保持完整精度，不会把部分结果当作成功输出。

CLI/MCP 的同步引擎命令保持同步返回，使用同样的计算保护；WASM 仍同步计算，本轮没有实现 Web Worker。

## 画布

首次显示及切换文档时先显示该文档的画板，再后台渲染图稿；不会借用其他文档的图像。
普通命令提交新修订时也在后台渲染，避免大描摹结果第一次显示时又阻塞界面。
轻量拖动预览继续即时渲染，耗时画布沿用后台刷新和旧图像重投影。
后台仅保留一个正在计算的任务、一个最新请求和一个结果；过时请求不积压，旧文档或旧修订结果不上传。
当前正在运行的栅格渲染仍完成后丢弃，本轮没有加入渲染器内部的抢占，也没有实现局部重绘或 GPU 栅格后端。

## 验证

使用自行生成的图形和图片检查描摹结果、取消/超时/工作量限制、过时结果、单步撤销、请求替换和首帧后台提交。
完整 `cargo xtask ci` 的 7 个步骤通过，共 4,721 项测试通过、4 项忽略。
回归覆盖运行中参数显示、滑块松开前取消旧任务、新修订后台渲染及图形上下文重建。
本机使用独立测试应用及自行生成的图片检查后台描摹、取消后原稿完整性、编辑/切换文档后的旧结果拒绝、
完成后的单步撤销和扩展；不对用户正在编辑的作品进行强杀或破坏性测试。
发布模式 CLI 的 50,000 路径性能场景通过全部 10 项现有预算；这些结果不是任意文档的帧率保证。

操作仅涉及虹构代码和应用包，不修改系统设置，不增加网络服务、图片上传或遥测。
