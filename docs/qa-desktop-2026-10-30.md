# Windows/Linux 扩展功能与性能验收

本轮针对两端预览版扩展按钮、命令、工具、面板、文件格式和性能检查。只使用原创合成图形与文字，
不读取用户作品或偏好，不使用其他商业绘图软件。Mac 安装包和已有 Release 附件保留。

## 修正

- 自定义窗口的最小化、最大化/还原、关闭按钮补齐可访问名称和按钮角色；原先只有悬浮提示。
- 原生“另存为”对话框此前从登记表选中格式 3，而实际默认编码器已是格式 4。
  现在默认保持当前格式，避免无意退回旧版的内联数据与兼容转换；仍可明确选择旧版本。
- 原生打开与预览提取不再先完整扫描 JSON、随后再次解码。一次解码后验证 JSON/二进制段边界，
  保留旧版本、压缩、预览、PDF、资源偏移检查及尾部垃圾拒绝。未更改文件内容或几何精度。
- 已修复的极端变换/画板参数从命令模糊测试排除表移除，重新纳入完整扫描。

## 可重复测试

- `RUST_TEST_THREADS=1 cargo xtask ci`：整个工作区的格式、严格 Clippy、测试、资产/品牌/层级和 WASM 门禁。
- 原生 UI 回归用实际指针事件点击全部工具抽屉按钮（800/1440 点宽），检查工具选择结果；
  顶栏的撤销、重做、搜索、新建、主页及文档返回、检查器切换、隐藏/恢复和面板菜单分别检查行为。
  全部 UI 命令在无文档、单对象和混合对象状态下扫描安全性与文档不变量。
- `packaging/smoke.py --desktop --extended --bin-dir … --output …`：真实桌面基础流程及扩展矩阵。
  矩阵包括 39 个面板的宽窄布局、15 个偏好页、119 项偏好存取/恢复、四档主题与玻璃开关、
  9 个工作区、浮出面板、54 个效果的取消/确认/渲染/撤销、全部可写格式与兼容版本、
  Pathfinder、剪贴板及中文文字。每项保存独立结果，任何失败都会使功能验收失败。
  另覆盖描摹预设/白色孔洞透明度/模式/调色板/阈值/视图/扩展/释放，以及 RGB/灰度/CMYK JPEG
  的基线、优化、渐进与多次扫描组合；使用独立 PNG 像素解析核对颜色和 alpha，拒绝缺失像素的 JPEG。
- Windows 流程执行整个工作区的原生 Rust 测试；MSI 安装版、便携版分别在新机器运行相同桌面矩阵。
  Linux 流程在最小 Ubuntu 环境安装 DEB 并执行相同矩阵，另检查便携包和 AppImage。
  Windows 另运行默认忽略的五项 release 性能测试，包括描摹、几何合并、像素滤镜、目录查询和密集拖动。
- `python packaging/performance.py --cli … --output …` 保留原有 50,000 路径的十项预算、耗时和失败状态。
  CI 的性能测量单独保留日志/JSON；超预算仍标记失败。预览打包允许保留这些测量，不能据功能构建成功推断性能通过。

## 基线与结果

本地候选源码通过完整七项门禁：4,795 项测试通过、0 失败、5 项保留默认忽略，20 个 WASM 模块检查通过。
其中 UI 为 944 项通过；新增五组 UI 回归另验证按钮分派及命令安全性。

已发布预览 17 在本次 Linux X11/Vulkan/llvmpipe 环境完成旧矩阵 342 项，全部通过。
本轮持久矩阵另补充原生格式 3 的兼容导出，结果以对应版本的运行记录为准。
描摹/JPEG 的复用脚本已在该真实桌面验证 71 项通过，并等待后台描摹完成后才检查提交、渲染和撤销。

同一预览 17、空闲四核环境的性能基线：

| 操作 | 耗时 | 原预算 |
|---|---:|---:|
| 整页渲染 2880×1800 | 191.05 ms | 100 ms |
| 平移后台重绘 | 188.93 ms | 100 ms |
| 400% 放大渲染 | 62.21 ms | 16 ms |
| 命中测试/点击 | 1.03 ms | 2 ms |
| 原生保存 | 124.63 ms | 300 ms |
| 原生打开 | 562.72 ms | 300 ms |
| SVG 导出 | 335.50 ms | 500 ms |
| 1,000 路径合并 | 97.59 ms | 150 ms |
| 5,000 锚点控制柄拖动/移动 | 16.72 ms | 8 ms |
| 5,000 锚点线段拖动/移动 | 6.89 ms | 8 ms |

基线五项超预算；不能把单次云端测量推广为全部设备的性能。修正后的原生运行和最终交付结果另补充于此。

## 覆盖边界

命令登记、安全扫描、面板可打开、偏好可存取均不等于功能全部实现。
Touch Type、3D/材质、Variables、部分窗口排列等仍以[路线图](../ROADMAP.md)为准。
参数组合、真实显卡、数位板、输入法候选窗口、多显示器 DPI、物理打印、系统文件选择器/portal、
Fedora/RPM 安装、ARM64 与外部复杂作品集没有被这些合成测试全部覆盖。
Windows 为未签名预览包。截图及结构化证据为测试产物，不作为应用资产。
