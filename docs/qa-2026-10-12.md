## 本轮修复

1. **拖动中按 Esc 没有结束编辑。** 选择、直接选择、编组选择和钢笔存在此问题。
   现在取消会还原本次拖动，不增加撤销步骤，随后到达的鼠标松开事件不会重新改图。
2. **拖动中切换工具留下旧的编辑状态。** 在统一切换边界收尾预览，保留批量操作
   的快照所有权，避免后续工具操作混进前一次撤销记录。
3. **长面板与浮动面板压住提示栏/状态栏。** 按实际工作区底边限制位置及滚动高度，
   不只修图像描摹，也覆盖字形、分色和其他面板。
4. **中文界面漏译。** 补齐液化工具名称、透视控件角落位置和拖动提示；颜色主题亮度、
   文档单位、普通分色色版名称走翻译。用户命名、专色名、字体名和保存值保持原样。

这些修复没有替换绘图算法、改变原生格式或扩大应用权限。

## 自动化与验收

新增 `crates/engine/tests/tool_sweep.rs`：

- 90 工具×3 图稿状态×3 修饰键×3 结束方式，共 **2,430 组交互场景**。
- 结束后无悬挂编辑，文档树合法，可原生/SVG 序列化，并可撤销回操作前图稿。
- 工具持久化设置切换后保留；选择/钢笔 Esc 取消与迟到的松开事件单独检查。
- 特定工具可以拒绝不适用的通用图稿；拒绝后安全性通过不等于功能正确性通过。

界面回归增加全部浮动面板避让状态栏检查，并让现有全图标面板测试检查工作区底边。
完整质量检查使用 `cargo xtask ci`，包含格式、静态检查、工作区测试、资源署名、
品牌、分层与 WebAssembly 编译。另执行默认跳过的 4 项耗时性能测试，
以及合成 50,000 路径性能基准。

修复后的完整回归：**4,672 项通过，0 失败**，7 道质量检查全部通过。
通常跳过的 4 项性能测试另行通过；它们不包含在 4,672 项里。

预览 5 发布复核另修正并行测试的共享状态干扰：界面语言按测试线程隔离，
菜单缓存断言考虑其他测试安装插件造成的有效刷新；正式版语言和插件行为不变。
新增语言隔离回归后，`cargo xtask ci` 为 **4,673 项通过，0 失败**，7 道检查全部通过。

修复后的发布构建已完成实机复查：

- 选择/钢笔取消、切换工具撤销及中文面板共 11 项定向检查通过。
- 90 个工具、90 个工具选项入口、78 次面板打开和 134 项首选项/页面检查通过。
- 54 种默认效果和 81 组保存/导出检查在修复构建上再次通过。
- 37 组外观/布局检查通过；在 950×700 窗口把图像描摹面板放到最下缘，
  内容区仍可滚动到“预览”“更新描摹”“扩展”，且不遮挡提示栏、状态栏。
- 平滑合成折线从 81 个锚点预览为 2 个；取消还原 81 个，提交只增加一步撤销。
- 图像描摹 43 组复查通过。13 个预设的透明 PNG 均检查像素：忽略白色开启时
  白色背景透明、主体不透明，关闭时背景不透明。包括高保真预设。
- 关闭描摹预览后修改设置不增加撤销记录，未应用时扩展被拒绝；应用后增加一步。
- 50,000 路径性能基准的 10 项均在预算内。修复后运行时机器负载较高，
  该次耗时只作参考，不能作为空闲机器性能或无卡顿的保证。

## 明确未覆盖

- **Touch Type 尚未实现**，登记入口当前是空操作，不能列为可用工具。
- 通用拖动不是专用工作流验收。宽度、符号、透视、混合、实时上色、文字路径等
  仍依靠各自现有专项测试；本轮没有穷举其所有图稿、修饰键和选项组合。
- 首选项可保存不等于效果已实现。项目仍有仅存储、尚未接入行为的选项；
  代码检查确认的例子有“显示打印尺寸”“突出显示替代字形”“以标签页打开文档”
  和“实时绘制和编辑”。不以本轮读写测试为它们背书，也没有逐项补实现这些能力。
- 禁用的占位菜单仍存在，例如 3D 与材质、变量、SVG 交互、拼写检查和部分窗口排列。
  这些是尚未实现的能力，不属于已通过的功能。
- 图像描摹仍同步计算；合成图片通过不保证所有大照片、高保真参数都不会长时间等待。
- 没有穷举全部效果参数、导出高级选项、打印设备、色彩设备、第三方插件和真实复杂文档。
- 崩溃恢复已有引擎和界面自动化回归，但本轮不强杀用户 App，不对真实作品做断电恢复演练。
- Windows、Linux、浏览器、数位板压力/倾斜、系统输入法候选窗和跨平台无障碍未做实机验收。

```sh
cargo test -p vectorcraft-engine --test tool_sweep

cargo test -p vectorcraft-ui-egui dock::tests
cargo test -p vectorcraft-effects -p vectorcraft-trace -p vectorcraft-pathops --release -- --ignored --nocapture
cargo run --release -p vectorcraft-cli -- perf
```

图像描摹面板置于窗口下缘，再缩小窗口；用有白底的合成图片描摹并勾选忽略白色，
导出透明 PNG 检查透明通道；检查平滑预览、取消及一次拖动对应一个撤销步骤。
